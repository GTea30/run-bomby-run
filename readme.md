# Submission for the GMTK Game Jame 2026
https://itch.io/jam/gmtk-jam-2026
https://gtea.itch.io/run-bomby-run

## Controls
WASD / Arrow Keys: Move

Space: Set timer to explode

Esc: Options Menu

## About
An evil bomb disposal squad is after you! Run until you have found a safe place to release your explosive anxiety!

My first game and submission to a game jam! I didn't get as much done as I was originally hoping, but I was also learning as I jammed.
